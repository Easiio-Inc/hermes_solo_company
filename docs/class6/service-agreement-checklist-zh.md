# 服务协议检查清单

在把高风险问题升级到人工复核之前，先用此清单对服务协议做首轮审查。

## 核心部分

```text
[ ] 工作范围是否足够明确。
[ ] 付款条款是否定义金额、时间和逾期后果。
[ ] 退款/取消条款是否说明客户提前停止时会发生什么。
[ ] 时间线/交付条款是否定义截止时间、验收点和批准流程。
[ ] 知识产权归属是否说明交付物、工具和既有材料归谁。
[ ] 保密义务是否合理。
[ ] 终止条款是否说明双方如何退出。
[ ] 责任限制是否存在且商业上合理。
[ ] 争议解决/适用法律条款是否清晰可见。
```

## 常见高风险信号

- 无限责任
- 没有上限的广泛赔偿义务
- 客户可无明确流程地拖欠付款
- 单方终止且没有补救期
- 超出已付款交付物范围的知识产权转让

## 人工复核闸门

如果条款实质影响责任暴露、付款暴露、知识产权归属或终止权利，应升级到人工复核。
