# 第 6 课人工复核清单

当 AI 将某个条款标记为高风险或不确定时，使用此清单。

## 人工复核材料包

```text
[ ] 复制原始条款文本。
[ ] 记录文档类型。
[ ] 记录 AI 给出的风险标签。
[ ] 解释为什么这个条款可能有风险。
[ ] 列出未知事实或歧义措辞。
[ ] 决定下一位应复核的人。
```

## 升级规则

- 如果条款改变责任、赔偿、付款暴露、隐私义务或争议权利，应升级给律师。
- 如果公司不确定某项承诺是否真的能在运营中做到，也应升级给创始人/运营负责人。
- 如果措辞影响个人数据处理、保留或共享，应升级给隐私/合规复核人。

## 必须提醒

这不是最终法律意见。
AI 输出用于整理审查，但高风险决定仍需人工批准。
如果业务影响重大，在签署、发布或执行前应升级给律师。
