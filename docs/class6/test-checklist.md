# Class 6 Test Checklist

Use this checklist after running a Class 6 legal/compliance review prompt.

## Core review boundary

```text
[ ] The output clearly says this is first-pass review support.
[ ] The output does not claim to be final legal advice.
[ ] The output tells the student to send high-risk clauses to human review.
```

## Output checklist

```text
[ ] Document type is identified correctly.
[ ] The model quotes or references the risky clause text.
[ ] Risk levels are labeled low / medium / high.
[ ] high-risk clauses are explicitly marked.
[ ] Missing facts or ambiguous wording are listed.
[ ] Recommended next step is practical.
[ ] No invented legal facts appear.
[ ] No statement says the AI replaced a lawyer.
```

## High-risk clauses to look for

```text
[ ] Unlimited liability
[ ] Broad indemnity
[ ] One-sided termination rights
[ ] Auto-renewal without clear notice
[ ] Data sharing without clear disclosure
[ ] Cross-border transfer or retention wording that is unclear
```

## Human review gate

```text
[ ] Every high-risk clause is escalated to human review.
[ ] The reviewer can explain why the clause is risky.
[ ] The reviewer can say what facts are still missing.
[ ] The reviewer can name the next human owner: lawyer, founder, or compliance lead.
```
