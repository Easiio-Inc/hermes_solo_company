# Legal Review Demo Documents

These sample documents are intentionally flawed for Class 6 Legal & Compliance Agent demos.

They are designed to trigger meaningful findings in the legal review workflow:
- privacy/data handling risks
- one-sided liability and indemnity
- weak termination/cancellation terms
- vague IP ownership
- missing retention/security/user-rights details
- unilateral changes and auto-renewal

## Suggested demo order
1. `bad-privacy-policy.md`
2. `bad-saas-terms.md`
3. `one-sided-contractor-agreement.md`
4. `risky-data-processing-addendum.md`

## Suggested document types
- `bad-privacy-policy.md` -> `privacy`
- `bad-saas-terms.md` -> `terms`
- `one-sided-contractor-agreement.md` -> `contract`
- `risky-data-processing-addendum.md` -> `contract` or `privacy`

## Teaching note
These are teaching/demo drafts only, not production legal templates.
