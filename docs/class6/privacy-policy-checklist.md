# Privacy Policy Checklist

Use this checklist for a first-pass review of a privacy policy before any publishing or customer-facing launch. Escalate material issues to human review.

## Core sections to verify

```text
[ ] data collected is named clearly.
[ ] purpose of collection is understandable and tied to a business use.
[ ] cookies/tracking tools are disclosed in plain language.
[ ] third-party tools or processors are named or described clearly.
[ ] user rights/contact method explains how a person can request help.
[ ] retention/security language explains how long data is kept and how it is protected.
```

## Common high-risk signals

- broad data collected with no clear purpose
- sharing with partners or service providers without enough detail
- vague or indefinite retention promises
- no user-rights contact path
- security claims that may be stronger than actual operations

## Human review gate

If the wording affects privacy/data handling, cross-border transfer, retention obligations, or third-party sharing promises, send it to human review.
