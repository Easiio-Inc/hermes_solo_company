# 隐私政策检查清单

在发布任何面向客户的隐私政策前，先用此清单做首轮审查。重大问题要升级到人工复核。

## 核心部分

```text
[ ] 收集哪些数据写得清楚。
[ ] 为什么收集这些数据能够被理解，并与业务用途对应。
[ ] Cookies / 追踪工具是否以清晰语言披露。
[ ] 第三方工具或处理者是否有明确说明。
[ ] 用户权利/联系方式是否说明用户如何发起请求。
[ ] 保留/安全语言是否说明保存多久以及如何保护。
```

## 常见高风险信号

- 收集范围很广，但用途不清楚
- 与合作伙伴或服务商共享数据但缺少足够细节
- 保留期限模糊或无限期
- 没有用户权利联系路径
- 安全承诺比真实运营更强

## 人工复核闸门

如果措辞影响隐私/数据处理、跨境传输、保留义务或第三方共享承诺，应升级到人工复核。
