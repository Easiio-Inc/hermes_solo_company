# 服务条款检查清单

用此清单对网站或产品服务条款做首轮审查。涉及重大业务风险或存在歧义的问题应升级到人工复核。

## 核心部分

```text
[ ] 可接受使用规则是否写清楚。
[ ] 付款/退款语言是否与真实业务政策一致。
[ ] 账户或用户义务是否具体且可执行。
[ ] 订阅/续费规则是否披露时间和取消方式。
[ ] 暂停/终止条款是否过于单方。
[ ] 责任限制和免责声明是否清晰可见。
[ ] 更新/通知机制是否说明用户如何知道变化。
```

## 常见高风险信号

- 自动续费但通知不足
- 一刀切不退款
- 平台可自行决定暂停账户
- 用户义务模糊，难以一致执行
- 缺少更新通知流程

## 人工复核闸门

如果语言影响计费承诺、账户访问、争议权利或面对用户的承诺，应升级到人工复核。
