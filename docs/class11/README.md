# Class 11 — AI Market Research Agent

This folder contains classroom documentation for **Class 11**, focused on turning raw market evidence into a clear product, service, or niche recommendation.

## Included materials

- developer build spec and lesson plan
- implementation plan
- page content draft
- teacher handout
- reusable Class 11 market research skill copy

## Purpose

These docs help students learn how to:

- define a market clearly before researching it
- work from pasted evidence instead of vague opinions
- identify repeated customer pain points
- compare competitors and find underserved gaps
- rank opportunities instead of chasing random ideas
- leave class with one practical niche recommendation and next validation step

## Notes

- Keep these files source-oriented and reusable.
- Avoid storing generated binaries or large exports here unless they are explicitly needed as packaged teaching assets.
- Do not store credentials, tokens, or paid-platform secrets in this folder.
