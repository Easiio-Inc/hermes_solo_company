# 第 7 课 PPT 第 25–27 页内容规划

> 主题：AI 品牌与视觉系统（Class 7 / Brand Studio）
>
> 目标：把前面已经完成的品牌方向、prompt pack、设计系统，收束为“可直接用于网站落地”的 3 页课堂内容。

---

## 这 3 页在整节课中的作用

如果前 1–24 页已经完成：
- 为什么要做品牌系统
- 如何从业务 brief 生成 3 个方向
- 如何选择 1 个最终方向
- 如何生成 logo / hero / social prompts
- 如何生成 design system

那么第 25–27 页最适合承担的是：
1. **第 25 页：把品牌方向接到首页结构**
2. **第 26 页：把视觉系统接到具体执行素材**

这样课程会从“生成想法”顺利走到“能上线的执行方案”。

## 第 25 页：品牌系统如何落到首页 Homepage

### 建议页标题
**第 25 页｜把品牌方向翻译成首页结构**

### 这一页的教学目标
让学生理解：品牌不是一句口号，也不是一套颜色，而是要体现在首页每一个关键区块里。

### 页面核心信息
可用 6 个区块来讲：
1. Hero 首屏
2. Trust Bar / 信任条
3. Offer / 服务卡片
4. Social Proof / 用户评价
5. About Founder / 创始人介绍
6. Final CTA / 底部行动区

### 推荐页面文案结构
**大标题**
- 选定一个品牌方向后，下一步不是继续想 logo，
- 而是把它翻译成首页每一个区块的 copy 和视觉规则。

**左侧：区块映射表**
- Hero：一句话价值承诺 + 一个主 CTA + 一张符合品牌方向的首屏图
- Trust Bar：用客户类型、成果、媒体/平台信息建立信任
- Offer Cards：每个服务卡片都要体现同一品牌语气
- Social Proof：评价内容要支持品牌定位，而不是泛泛夸赞
- Founder Section：强调为什么你值得信任
- Final CTA：重复承诺，推动预约/咨询/购买

**右侧：课堂提示**
- 同一品牌方向，要贯穿标题、按钮、图片、配色、留白
- 不要每个区块换一种风格
- 网站首页不是“信息堆积”，而是“同一定位的连续证明”

### 版式建议
- 左侧放 **Homepage 结构图** 或 6 行区块卡片
- 右侧放 **Do / Don’t**
  - Do：统一语气、统一图片风格、统一 CTA
  - Don’t：每个区块都像不同网站拼起来

### 讲师讲稿提示
- “学生最容易犯的错，是做完品牌方向后，又回到随便写网站文案。”
- “第 25 页要让他们明白：品牌方向要变成首页结构规则。”
- “这也是 Brand Studio 里 website workflow 的真正用途。”

## 第 26 页：把视觉系统变成可执行素材包

### 建议页标题
**第 26 页｜从设计系统到素材执行清单**

### 这一页的教学目标
让学生看到：品牌系统最后必须输出为一组可制作、可外包、可交给 AI 工具生成的素材任务。

### 页面核心信息
这一页重点讲 4 类素材：
1. Logo concept prompt
2. Hero/banner image prompt
3. Social post prompt
4. Website illustration / section image prompt

### 推荐页面文案结构
**大标题**
- 设计系统不是终点。
- 你还要把它转成一套任何人都能执行的素材说明书。

**中间主内容：素材包清单**
- **Logo Prompt**：说明风格、图形感觉、避免元素、适用场景
- **Hero Prompt**：说明画面主体、情绪、构图、光线、产品/服务场景
- **Social Prompt**：说明正方形内容、标题层级、品牌视觉统一性
- **Website Visual Prompt**：说明插图、卡片图、功能图、服务图的统一风格

**补充一栏：每条 prompt 至少要包含**
- 目标用户是谁
- 品牌语气是什么
- 希望传达什么感觉
- 不能出现什么廉价/跑偏元素
- 这张图要用在什么位置

### 课堂上的关键结论
- Prompt 不是越长越好，而是越清楚越好
- 所有素材都要服务于同一个品牌方向
- 网站图、社交图、banner 图不能各说各话

### 版式建议
- 用 4 张卡片横向/2x2 布局
- 每张卡片包含：
  - 素材类型
  - 作用
  - prompt 必含字段
  - 常见错误

### 可直接放在页上的“常见错误”
- Logo 太花，失去可识别性
- Hero 图很漂亮，但不支持业务定位
- 社交图风格和网站首页完全不同
- 每张图都像不同品牌做的

### 讲师讲稿提示
- “第 26 页要把抽象的品牌词，变成可交付的素材任务。”
- “这一步做完，学生就能把结果交给 Hermes、设计师、或 AI 出图工具。”
- “你不是在收集灵感，而是在形成 production-ready asset pack。”

## 第 27 页：课堂作业 / 交付标准 / 检查清单

### 建议页标题
**第 27 页｜本课交付物：你要交什么，怎么算完成**

### 这一页的教学目标
把第 7 课从“学懂了”变成“交得出来”。

### 建议交付物（课堂作业）
学生在课后或课堂内，至少提交下面 5 项：
1. **品牌 Brief**
2. **3 个品牌方向 + 选定 1 个最终方向**
3. **Prompt Pack**（logo / hero / social / website）
4. **Website-ready Design System**
5. **Homepage Application Plan**（首页各区块怎么应用）

### 建议完成标准
**完成 = 同时满足这 5 个标准**
- 有明确目标客户，不是模糊表达
- 有且只有 1 个最终品牌方向
- Prompt pack 能直接被使用
- 网站首页的 hero / cards / CTA 已经有明确应用规则
- 整体视觉语言一致，没有“拼凑感”

### 可直接上 PPT 的检查清单
**提交前自查：**
- 我的品牌承诺是否能用一句话说清楚？
- 我的首页首屏是否体现这个承诺？
- 我的 CTA 是否和目标用户匹配？
- 我的图片风格是否在首页和社交媒体里一致？
- 我的设计系统是否真的能指导网站制作？

### 建议收尾文案
**一句总结**
- 第 7 课的目标，不是得到“很多设计灵感”，
- 而是产出“一套能直接进入网站执行的品牌系统”。

**下一步引导**
- 下一步可以进入网站模板应用、页面制作、素材生成与上线流程。

### 版式建议
- 左侧：5 个交付物清单
- 右侧：完成标准 + 提交前自查框
- 底部：一句收尾金句 / Next Step

### 讲师讲稿提示
- “这一页非常重要，因为它把课程变成可验收的作业。”
- “如果学生交不出 homepage application plan，就说明他还停留在灵感层面。”
- “我们的标准不是好不好看，而是能不能进入网站执行。”

## 建议的 25–27 页整体叙事节奏

### 25 页
**从品牌方向 → 首页结构**

### 26 页
**从设计系统 → 素材执行包**

### 27 页
**从课堂学习 → 可提交的作业成果**

这个顺序的好处是：
- 先讲“怎么应用到网站”
- 再讲“怎么形成素材执行包”
- 最后讲“学生到底要交什么”

非常适合 AI Solo Company 这种强调落地和交付的课程风格。
