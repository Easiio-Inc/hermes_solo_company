# 第 7 课 PPT 第 22–30 页扩展规划

## 目标
把原来的第 25–27 页内容规划，扩展成一个更完整、可直接讲课的 9 页片段，并同步准备讲师 speaker notes。

## 页面结构

### 第 22 页｜从业务 Brief 到品牌 Brief
- 说明为什么品牌不是“审美选择”，而是“业务定位翻译器”
- 输入：客户、产品、价格、目标用户、竞争差异
- 输出：一句话品牌承诺 + 语气 + 视觉方向边界
- 课堂重点：先定业务，再谈视觉

### 第 23 页｜Brand Studio 的 3 个方向怎么来的
- 解释为什么要生成 3 个方向，而不是只出 1 个
- 方向示例：Modern Operator / Warm Guide / Premium Builder
- 每个方向都要回答：适合谁、感觉是什么、首页会长什么样
- 课堂重点：3 个方向是为了比较，不是为了全部保留

### 第 24 页｜如何选出 1 个最终方向
- 评估维度：目标客户匹配、转化能力、执行一致性、后续素材可扩展性
- 常见错误：选“最好看”的，不选“最适合业务”的
- 输出：选定 1 个 winner，进入后面的 prompt pack / design system / website workflow

### 第 25 页｜把品牌方向翻译成首页结构
- Hero / Trust Bar / Offer Cards / Social Proof / Founder / Final CTA
- 重点：品牌方向如何变成 homepage 各区块文案与视觉规则

### 第 26 页｜从设计系统到素材执行清单
- Logo prompt / Hero prompt / Social prompt / Website visual prompt
- 重点：品牌系统必须变成 production-ready asset pack

### 第 27 页｜本课交付物：你要交什么，怎么算完成
- 5 项交付物
- 完成标准
- 提交前自查

### 第 28 页｜课堂 Demo 流程：老师现场怎么演示
- Step 1：输入业务 brief
- Step 2：生成 3 个方向
- Step 3：选 1 个方向
- Step 4：生成 prompt pack
- Step 5：生成 design system
- Step 6：生成 homepage application plan
- 课堂重点：让学生看到完整 workflow，而不是零散功能

### 第 29 页｜学生实操流程：从 Brand Studio 到网站执行
- 学生先完成 brief
- 再选择方向
- 再生成素材 prompts
- 再把结果接入 homepage sections
- 可交给 Hermes / 设计师 / AI 出图工具继续执行

### 第 30 页｜收尾与下一步：进入网站模板应用
- 本课产出不是“灵感板”，而是网站可执行品牌系统
- 下一步进入页面制作、模板接入、素材生成、上线准备
- 强调课程节奏：Brand → Website → Assets → Launch

## 设计风格建议
- 深海军蓝 + 青绿色点缀 + 浅灰底
- 标题页/收尾页偏深色，内容页浅底卡片化
- 多用 2 栏、卡片、流程条，不做纯文字页
- 每页保留 1 句“课堂结论”做高亮

## Speaker notes 结构建议
每页 notes 建议包含：
1. 这一页要讲的核心结论
2. 学生最容易犯的错
3. 你要强调的一句话
4. 和下一页如何衔接
