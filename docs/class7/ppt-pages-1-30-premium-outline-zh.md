# 第 7 课 PPT 1–30 页高级版大纲

## 总体目标
把 Class 7「AI 品牌与视觉系统」做成一套更完整、更高级、更适合课堂演示与课后交付的 30 页课件。

## 建议节奏
- 1–3：开场、目标、为什么这一课重要
- 4–8：品牌系统的核心概念与业务关系
- 9–14：Brand Studio 输入与生成逻辑
- 15–21：方向选择、prompt pack、design system 形成
- 22–30：website workflow、demo、作业、下一步

---

## Pages 1–21 outline

### 第 1 页｜封面
- 标题：第 7 课｜AI 品牌与视觉系统
- 副标题：用 Brand Studio 把业务 brief 变成网站可执行品牌系统

### 第 2 页｜本课你会得到什么
- 品牌 brief
- 3 个视觉方向
- 1 个最终方向
- prompt pack
- design system
- homepage application plan

### 第 3 页｜为什么这课重要
- 没有品牌系统，网站容易拼凑
- 没有统一方向，素材会越做越乱
- 这课是品牌到网站执行的桥梁

### 第 4 页｜什么是品牌系统
- 不是 logo 而已
- 不是颜色而已
- 是承诺、语气、视觉规则、转化表达的统一系统

### 第 5 页｜这一课不做什么
- 不做无限审美探索
- 不保留 10 个方向
- 不把品牌课变成纯设计欣赏

### 第 6 页｜品牌系统和业务的关系
- 品牌不是装饰
- 品牌是商业定位的外显
- 品牌服务于信任与转化

### 第 7 页｜学生常见错误
- 先想 logo，再想业务
- 喜欢什么就选什么
- 网站和社交素材各做各的

### 第 8 页｜Brand Studio 最终要产出什么
- Brief
- 方向
- Prompt pack
- Design system
- Website workflow

### 第 9 页｜Brand Studio 输入项
- 公司 / 业务
- 用户是谁
- 卖什么
- 为什么信你
- 期望语气与边界

### 第 10 页｜输入示例
- 示例业务：AI Solo Company / SoloLaunch AI
- 示例用户：个人创业者 / 顾问 / 小团队
- 示例目标：快速上线、可信执行、统一品牌

### 第 11 页｜从输入到输出的逻辑
- 业务信息 → 品牌 brief
- 品牌 brief → 3 个方向
- 选方向 → prompt pack / design system / homepage workflow

### 第 12 页｜品牌 Brief 长什么样
- 一句话定位
- 目标客户
- 价值承诺
- 语气
- 视觉边界

### 第 13 页｜为什么先出 3 个方向
- 为了比较定位差异
- 为了帮助学生做判断
- 不是为了保留更多选项

### 第 14 页｜3 个方向示例
- Modern Operator
- Warm Guide
- Premium Builder

### 第 15 页｜方向 A：Modern Operator
- 适合卖系统与执行力
- 视觉特征：深色、强对比、仪表盘感
- 适合首页：结果导向、强 CTA

### 第 16 页｜方向 B：Warm Guide
- 适合顾问、教练、服务业务
- 视觉特征：柔和中性色、帮助感、专业感
- 适合首页：解释清晰、信任友好

### 第 17 页｜方向 C：Premium Builder
- 适合高客单价 B2B
- 视觉特征：高端、稳重、策略感
- 适合首页：强信任、强案例、强权威

### 第 18 页｜如何选出 1 个 winner
- 看目标客户匹配
- 看转化潜力
- 看执行一致性
- 看后续素材扩展性

### 第 19 页｜选定方向后先做什么
- 不继续发散
- 直接进入 prompt pack
- 进入 design system
- 进入 homepage application

### 第 20 页｜Prompt Pack 包含什么
- logo prompt
- hero prompt
- social prompt
- website visual prompt

### 第 21 页｜Design System 包含什么
- 颜色方案
- 字体与层级
- 图片风格
- CTA 语气
- 区块与留白规则
