# Class 10 Teacher Handout

Use this handout to run a live Class 10 session with clear teaching flow, example selection, and review-first decision points.

---

## Class goal
By the end of Class 10, students should be able to:
- classify a video request before jumping into production
- choose the right entry workflow with `video-generation-orchestrator`
- turn one business offer or website page into a first practical short-video batch
- identify the next best downstream skill
- leave class with a usable draft, not just abstract ideas

---

## Core teaching principle
Do not start with visuals.

Start with:
1. request classification
2. route decision
3. source extraction
4. first content batch
5. only then deeper production

This prevents students from jumping too early into cinematic generation or overcomplicated tools.

## Recommended live class flow

### Part 1 — Introduce the routing model
Explain that Class 10 is not only about writing hooks and scripts.
It is about choosing the right workflow first.

Teach these entry questions:
- Is the source mainly a website page?
- Is the source mainly documents or lesson notes?
- Is the message already clear and only visuals are missing?
- Is this a one-video request or a repeatable content system?

Main entry skill:
- `video-generation-orchestrator`

## What to emphasize while teaching

### 1. Entry skill matters
Students often want to jump straight to:
- Veo
- avatar tools
- editing tools
- cinematic promo generation

Correct framing:
- first choose the entry skill
- then choose the simplest downstream production path

### 2. The first draft is supposed to be rough
The workspace output is meant to:
- make the offer clearer
- generate a first useful hook bank
- create a reviewable short-video batch

It is not meant to produce final polished marketing content in one click.

### 3. Match the route to the business type
- service / course / class page -> usually `website-to-video-funnel`
- document-heavy / research-heavy -> often `notebooklm-to-video`
- already-approved script + strong visuals needed -> `google-veo-cinematic-video`
- beginner production assembly -> `ai-video-from-script`

## Sample instructor prompts

### Prompt 1 — Route first
```text
Use video-generation-orchestrator for this Class 10 request.
First return:
- video request classification
- recommended route
- recommended first downstream skill
- best next step
Then explain why that route fits better than the obvious alternatives.
```

### Prompt 2 — Extract first
```text
Use website-to-video-funnel.
Extract the offer summary, audience pain points, proof points, CTA map, and 5 strongest short-video directions from this business context.
Keep it review-first and practical.
```

### Prompt 3 — Build the first batch
```text
Use short-video-content-factory.
Turn the approved source angles into:
- 10 topics
- 10 hooks
- 3 scripts
- platform captions
- a 5-video first-week batch plan
```

---

## Common mistakes to correct in class
- trying to explain three offers in one video
- starting with a vague source paragraph
- choosing cinematic generation before message clarity
- confusing a first-draft pack with a final publish-ready campaign
- writing generic CTA language with no real next step

---

## Review questions for students
Ask each student:
- What is your business in one sentence?
- What is the single clearest offer?
- Which route did the orchestrator recommend?
- What is the first artifact you should generate?
- Which one of your 10 topics is strongest?
- Which route is realistic for you this week?

---

## Suggested homework
Each student should submit:
- one approved offer summary
- one approved route decision
- one 10-topic list
- one 10-hook list

- one first-week 5-video batch plan

Optional advanced homework:
