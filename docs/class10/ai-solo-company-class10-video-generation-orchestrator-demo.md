## 2) Video Request Classification / 视频请求分类

**English**
- Primary job type: mixed workflow with a strong website-to-video starting point
- Source material state: existing website/class page copy plus reusable teaching material
- Grounding sensitivity: medium to high because the class promise should stay aligned with the actual curriculum
- Visual ambition: medium for the first batch, with optional cinematic upgrades later
- Likely best route: `website-to-video-funnel -> short-video-content-factory -> ai-video-from-script`
- Optional upgrade path: `website-to-video-funnel -> short-video-content-factory -> google-veo-cinematic-video`

**中文**

- 源材料状态：已有网站 / 课程页面文案，加上可复用的教学内容
- 对事实一致性的要求：中高，因为课程承诺必须和真实教学内容保持一致
- 画面野心：第一批以中等为主，之后可以选择性升级成更电影感的内容
- 最可能的最佳路线：`website-to-video-funnel -> short-video-content-factory -> ai-video-from-script`
- 可选升级路线：`website-to-video-funnel -> short-video-content-factory -> google-veo-cinematic-video`

## 3) Recommended Route / 推荐路线

### Best default route for Class 10 / 第 10 课默认最佳路线
1. `video-generation-orchestrator`
2. `website-to-video-funnel`
3. `short-video-content-factory`
4. `ai-video-from-script`

### Why this route fits / 为什么这条路线合适

**English**
- The source already exists as website and class-page messaging, so the first bottleneck is extraction and framing, not writing from zero.
- Students need practical short-video angles, hooks, and scripts more than cinematic visuals at the start.
- `website-to-video-funnel` is the cleanest first downstream skill because it can mine offers, pain points, proof ideas, and CTA language from the page copy.
- `short-video-content-factory` can then turn those extracted angles into a usable first batch.
- `ai-video-from-script` is a practical assembly path for beginner-friendly production because it helps convert the winning script into narration, pacing, captions, and edit instructions.
- Cinematic generation should stay optional until the strongest topic is already approved.

**中文**
- 源材料已经存在于网站和课程页面里，所以第一个瓶颈不是从零写脚本，而是先做内容提炼和 framing。
- 对学员来说，第一步更需要的是可执行的选题、Hook 和脚本，而不是一开始就追求电影感画面。
- `website-to-video-funnel` 很适合作为第一个下游技能，因为它能从页面文案中提炼报价、痛点、证明点和 CTA 表达。
- 然后 `short-video-content-factory` 可以把这些提炼结果转成第一批实际可用内容。
- `ai-video-from-script` 很适合新手制作，因为它能把胜出的脚本继续转成旁白、节奏、字幕和剪辑说明。
- 在最强选题没有被确认之前，电影感生成应该保持为可选升级，而不是默认第一步。

## 6) Decision Gates / 决策检查点

**English**
- Gate 1: approve the extracted class messaging before building the content batch
- Gate 2: approve the strongest topic before deeper production prep
- Gate 3: approve the 30-second script before recording, TTS, avatar, or editing work
- Gate 4: only move to cinematic generation if the message is already proven and the student wants a promo-style upgrade

**中文**
- 检查点 1：先确认提炼出的课程表达，再进入批量内容生成
- 检查点 2：先确认最强选题，再进入更深的制作准备
- 检查点 3：先确认 30 秒脚本，再进入录制、TTS、数字人或剪辑
- 检查点 4：只有当信息表达已经成立，而且学员确实想升级成宣传片风格时，才进入电影感生成

---

## 7) Risks and Constraints / 风险与约束

**English**
- Messaging drift risk: if the class promise is overstated, the videos can sound more ambitious than the actual curriculum
- Scope risk: students may try to mix every class outcome into one short video instead of focusing on one pain point
- Production risk: jumping to AI promo visuals too early can hide weak messaging instead of fixing it
- Classroom risk: the first batch should stay simple enough that students can actually produce it this week

**中文**
- 表达漂移风险：如果课程承诺被说得过大，视频会显得比真实课程更夸张
- 范围失控风险：学员可能会想把所有课程结果塞进一条短视频，而不是聚焦一个痛点
- 制作风险：太早跳到 AI 宣传画面，可能会掩盖信息表达不清的问题
- 课堂执行风险：第一批内容必须足够简单，学员这周就能做出来
