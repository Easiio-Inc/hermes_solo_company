# Class 10 — AI Short-Video Production Guide

## Goal
Turn one business offer, website page, FAQ, blog post, case study, or course lesson into a repeatable short-video production workflow.

Students should leave Class 10 with:
- 10 short-video topics
- 10 hooks
- 3 scripts (15s / 30s / 60s)
- 1 storyboard
- platform caption pack
- 2-week publishing calendar
- one recommended production route

## Class 10 workflow

1. Start with `video-generation-orchestrator` to classify the request and choose the best entry skill
2. Extract the offer, audience, pain point, proof, and CTA
3. Group source material into content buckets
4. Generate 10 topic ideas
5. Generate 10 hooks
6. Write 3 scripts
7. Build 1 storyboard / shot list
8. Prepare platform-specific captions
9. Build a 2-week publishing calendar
10. Choose the easiest production route
11. Review performance and improve the next batch

## Content buckets
Use these buckets before generating videos:
- FAQ answers
- mistakes to avoid
- myths vs truth
- before / after
- mini case study
- founder insight
- tool walkthrough
- checklist / framework
- objection handling
- CTA / conversion

## Script structure
Each script should include:
- Hook
- Problem
- Solution or insight
- CTA

### 15-second version
Best for:
- one problem
- one lesson
- one CTA

### 30-second version
Best for:
- balanced explanation
- stronger trust-building
- clear next step

### 60-second version
Best for:
- mini framework
- case-study explanation
- educational authority content

## Recommended beginner tool routes

### Route A — Fastest beginner workflow
- Hermes for ideas, hooks, scripts, captions, calendar
- Canva for graphics
- CapCut for editing

### Route B — No-camera workflow
- Hermes for scripts and captions
- HeyGen or Synthesia for avatar delivery
- CapCut for editing

### Route C — AI promo workflow
- Hermes for shot list and prompts
- Flow / Runway / Kling / Luma for shots
- Hermes TTS or ElevenLabs for voice
- CapCut for assembly

## Good hook patterns
- Most people are doing this wrong.
- Before you pay for this, watch this first.
- If you want more leads, fix this one thing.
- Nobody tells you this about AI websites.
- Here is the fastest way to explain your offer.

## Platform adaptation

### TikTok / Reels
- faster pacing
- sharper hook
- casual tone
- visual movement early

### YouTube Shorts
- more searchable wording
- cleaner explanation
- stronger title clarity

### LinkedIn
- more professional
- insight-led
- founder / operator tone
- less exaggerated language

## Simple 2-week publishing rhythm
- Week 1: 3 educational videos + 1 objection video
- Week 2: 2 proof videos + 1 CTA video + 1 repurposed winner

## Review questions
After posting, ask:
- Which hook stopped the scroll?
- Which video held attention?
- Which CTA created real action?
- Which topic should become a series?
- Which weak video needs only a new hook?

## Expected student output
By the end of Class 10, each student should be able to show:
- one offer summary
- one short-video topic list
- one hook bank
- one 3-script pack
- one storyboard
- one publish calendar
- one selected production route
