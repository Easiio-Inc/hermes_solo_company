# Class 10 — Short Video Production and Solo Company Video Marketing

This folder contains classroom documentation for **Class 10**, focused on turning one business offer or lesson source into practical short-video production outputs.

## Included materials

- Chinese slide/deck outline and page-by-page content
- teacher handout and production guide
- reusable Class 10 video-generation orchestrator skill copy
- demo packs for:
  - AI Solo Company
  - mybnb
  - Yishunyuan factory
- bilingual student example for mybnb

## Purpose

These docs help students learn how to:

- classify a video request before choosing a tool
- route a request to the correct workflow
- create short-video topics, hooks, and scripts
- prepare Veo/cinematic prompt packs when needed
- keep video work practical, review-first, and classroom-safe

## Notes

- Keep these files source-oriented and reusable.
- Avoid storing generated media binaries or large exports here unless they are explicitly needed as packaged teaching assets.
- Do not store credentials, tokens, or paid-platform secrets in this folder.
