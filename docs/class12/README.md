# Class 12 — AI Customer Service and Sales Agent

This folder contains classroom documentation for **Class 12**, focused on turning inquiries, website leads, and chatbot conversations into structured customer-service and sales actions.

## Included materials

- developer build spec and lesson plan
- implementation plan
- teacher handout
- sample lead set
- AI Solo Company demo case
- reusable Class 12 skill copies

## Purpose

These docs help students learn how to:

- separate customer-service questions from sales opportunities
- score leads before spending time on follow-up or quoting
- draft consultative email, DM, and call follow-up packages
- prepare CRM-ready notes and next actions
- connect the website assistant to a repeatable conversion workflow

## Notes

- Keep these files source-oriented and reusable.
- Avoid storing generated binaries or large exports here unless they are explicitly needed as packaged teaching assets.
- Do not store credentials, tokens, or paid-platform secrets in this folder.
