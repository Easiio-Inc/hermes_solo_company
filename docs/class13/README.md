# Class 13 — Commercialization and Skill Packaging

This folder contains classroom documentation for **Class 13**, focused on turning a working operator workflow into a sellable, teachable, and reusable business asset.

## Included materials

- class-level implementation plans
- teacher and student packaging notes
- reusable Class 13 website skill recorder publishing skill copy
- Chrome extension MVP scaffolding notes for recording website actions

## Purpose

These docs help students learn how to:

- capture one real operator workflow on a website
- review and redact the captured browser actions
- convert approved recordings into Hermes-ready skills
- decide whether a skill should stay private or be published for broader bot reuse

## Notes

- Keep these files source-oriented and reusable.
- Do not store secrets, customer data, or unreviewed browser exports here.
- If example payloads are added later, use synthetic demo data only.
