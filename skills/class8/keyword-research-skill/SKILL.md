# Keyword Research Skill

## Purpose
Use this student skill to practice Class 8 keyword research before writing a full SEO content brief.

## Input checklist
- Business / company
- Offer
- Audience
- Region
- Topic
- Seed keywords
- Optional site URL or proof points

## Output goals
1. Summarize the business context in one short section.
2. Expand the Seed keywords into a focused keyword cluster.
3. Identify one Primary keyword and several Supporting keywords.
4. Explain Search intent for the strongest keyword.
5. Suggest one practical content angle and a next action.

## Data source rule
- If DataForSEO or another verified source is available, you may mention that as evidence.
- If no live provider data exists, stay honest and frame the output as a classroom hypothesis.

## Guardrails
- Keep the output review-safe and classroom-friendly.
- Do not claim live search volume unless a tool actually provided it.
- Prefer clear, practical wording over vague SEO jargon.
- End with a next step that leads into the full Class 8 brief.

## Output format
## Keyword research brief
## Seed keywords
## Primary keyword
## Supporting keywords
## Search intent
## Suggested content angle
## Next action
