# SEO Audit Skill

## Purpose
Use this student skill in Class 8 before keyword research or content writing when you need a practical single-page SEO audit.

## Input checklist
- Page URL
- Page type
- Business / company
- Offer or topic
- Audience
- Region
- Optional notes from the reviewer

## Output goals
1. Summarize the page context clearly.
2. Identify current strengths worth keeping.
3. List the main SEO issues in student-friendly language.
4. Recommend the most important fixes first.
5. End with one next step that leads into a brief or article workflow.

## Guardrails
- Keep the audit review-safe and classroom-friendly.
- Do not claim a live crawl if one was not actually performed.
- Prefer practical issues such as title, meta description, heading structure, internal links, image alt text, and CTA clarity.
- Avoid backend details, secrets, or implementation-specific paths.

## Output format
## Audit summary
## Strengths
## Issues found
## Recommended fixes
## Next action
