## Purpose

Use these assets for repeatable workflows such as:

- auditing whether a student’s website, assistant, lead capture, CRM, and follow-up systems really work together
- validating the end-to-end business loop instead of checking isolated modules only
- preparing a reliable final demo with fallback evidence
- turning Class 14 findings into a structured launch plan, weekly SOP, and handoff package
- giving teachers a standard orchestration path and output format for final classroom delivery
