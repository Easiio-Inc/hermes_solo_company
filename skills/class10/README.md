# Class 10 Skills

This folder contains reusable skills and supporting classroom materials for **Class 10 — short-video production and solo company video marketing**.

## Current skills

### `class10-video-generation-orchestrator`
Student-editable routing workflow that classifies one business/video request and recommends the best starting path, including Veo-oriented cinematic generation when appropriate.

## Related packaged media skills

These supporting skills are also packaged in this repo under `skills/media/` because they are part of the broader Class 10 workflow:

- `video-generation-orchestrator`
- `website-to-video-funnel`
- `notebooklm-to-video`
- `short-video-content-factory`
- `ai-video-from-script`
- `google-veo-cinematic-video`

## Purpose

Use these assets for repeatable workflows such as:

- choosing the right video workflow before generating assets
- routing website, document, script, or offer-based requests into the correct toolchain
- keeping student video generation practical, review-first, and classroom-safe
- teaching the difference between strategy, scripting, cinematic prompting, and final assembly
