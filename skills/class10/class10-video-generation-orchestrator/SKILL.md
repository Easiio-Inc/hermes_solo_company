# Class 10 Video Generation Orchestrator

## Purpose
Use this Class 10 skill to decide **how a video request should start** before students jump into hooks, editing, or cinematic generation.

The goal is to turn one business offer, website page, FAQ, case study, or lesson note into a:
- workflow classification
- recommended entry skill
- practical first artifact
- first short-video content pack

## Input checklist
- Business / project
- Offer
- Audience
- Source material
- Primary CTA
- Tone
- Optional preferred route or tool

## Routing rule
Start by classifying the request.

### Start with `website-to-video-funnel` when:
- the source is mainly a website page, service page, FAQ, or offer page
- the message still needs to be extracted and organized

### Start with `notebooklm-to-video` when:
- the source is mainly notes, documents, PDFs, transcripts, or lesson material
- factual grounding matters more than cinematic polish

### Start with `short-video-content-factory` when:
- the message is already clear
- the student mainly needs topics, hooks, scripts, captions, and a publishing plan

### Start with `google-veo-cinematic-video` when:
- the message is already approved
- the main need is strong visuals, mood, and cinematic shot prompts

### Start with `ai-video-from-script` when:
- the script already exists
- the student needs storyboard, production planning, voiceover, captions, or assembly notes

## Output goals
1. Classify the request clearly.
2. Recommend the best entry skill.
3. Explain why that route fits.
4. Name the first artifact to generate next.
5. If short-video production is still the best route, produce a first-draft content pack.

## First-draft content pack
When the request is ready for short-video production, include:
- 10 short-video topics
- 10 hooks
- 3 scripts (15s / 30s / 60s)
- 1 storyboard or shot list
- platform caption suggestions
- 2-week publishing rhythm
- recommended production route

## Guardrails
- Do not jump straight to Veo or editing tools if the message is still unclear.
- Do not claim a platform or paid feature was used unless it was actually used.
- Keep the output classroom-safe, practical, and review-first.
- Prefer one clear offer per video.
- Keep CTAs realistic and specific.

## Output format
## Video request classification
## Recommended route
## Why this route fits
## First artifact to generate
## First-draft content pack
## Best next step
