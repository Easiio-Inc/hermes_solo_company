# Class 9 Skills

This folder contains reusable skills and supporting classroom materials for **Class 9 — GEO + WordPress MCP / safe AI website operations** in the Hermes Solo Company materials.

## Purpose

These assets define repeatable workflows for:
- reviewing SEO/GEO changes before touching production
- using WordPress MCP within a safe draft-first boundary
- demonstrating reversible live operations instead of one-way content generation
- teaching students the difference between preview, draft, and publish actions
- reinforcing production verification mindset during AI-assisted website work

## Notes

- Keep skill content reusable and stable.
- Keep the safe operator boundary explicit: preview first, use draft targets, verify live behavior, and avoid irreversible production edits during class demos.
- Do not put secrets, credentials, or environment-specific tokens into skill files.
