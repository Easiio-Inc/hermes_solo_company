# Class 9 GEO + WordPress MCP Demo

## Purpose
Use this skill to run or explain the Class 9 classroom demo focused on **GEO + WordPress MCP** and **safe AI website operations**.

The core lesson is not just generating SEO content. It is proving that Hermes can operate inside a controlled workflow:
- inspect first
- preview or target a safe draft
- perform a reversible change
- verify the live system behavior
- avoid unsafe direct production edits during teaching/demo flows

## When to use
Use this skill when you need to:
- present the Class 9 highlight
- teach students how GEO work fits with WordPress MCP
- run the safe draft-only demo flow
- explain why operator boundaries matter in AI-assisted website management
- package or hand off the Class 9 demo materials

## Input checklist
- Target WordPress site or classroom demo target
- Confirmed MCP connectivity/health
- Safe draft target/page/post available
- Reversible demo change selected
- Verification method for before/after state

## Demo goals
1. Show that the integration is healthy.
2. Show that authenticated MCP control works.
3. Show that draft-first operation is possible.
4. Show that the demo change is reversible.
5. Show that safe operator workflow is real, not theoretical.

## Recommended live demo flow
1. Show the health endpoint or equivalent health signal.
2. List live MCP tools or otherwise prove the integration is active.
3. Open a safe draft target rather than a production-critical page.
4. Run a reversible draft-only SEO/GEO write test.
5. Verify the result.
6. Restore or confirm reversible cleanup if needed.
7. Summarize what was proven.

## Teaching points
- GEO review comes before apply.
- Preview before apply.
- WordPress MCP must stay inside a clear control boundary.
- Production verification mindset matters more than flashy generation.
- Safe AI website operations are the real Class 9 message.

## Guardrails
- Prefer draft targets over live irreversible edits.
- Do not expose credentials, owner tokens, or API keys.
- Do not claim a tool is live unless the health/tool listing actually proves it.
- If the environment is degraded, teach the failure honestly rather than pretending the demo succeeded.
- Keep classroom operations reversible whenever possible.
