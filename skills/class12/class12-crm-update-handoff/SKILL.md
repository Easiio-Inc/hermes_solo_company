# Class 12 CRM Update Handoff

## When to use
Use this skill after a lead has been reviewed and the operator needs a **clean CRM handoff package**.

## Inputs
Collect when available:
- name
- company
- source
- lead score
- inquiry summary
- service interest
- budget
- timeline
- stage recommendation
- next action recommendation
- important objections

## Purpose
Turn messy chat, email, or call notes into:
- concise CRM summary
- stage recommendation
- follow-up task
- owner notes
- missing-data checklist

## Recommended stage examples
- new lead
- qualified
- proposal pending
- follow-up due
- nurture
- won
- lost

## Business rules
- Keep notes copy-paste ready.
- Separate facts from assumptions.
- Flag missing budget, timeline, or decision-maker info.
- If the lead is weak, recommend nurture instead of forcing an active deal stage.
- End with one clear operator action.

## Output format
## CRM summary
## Stage recommendation
## Follow-up task
## Missing information
## Operator next action

## Example prompt
Use the Class 12 CRM update handoff workflow.
Convert this inquiry into a CRM-ready summary and next-action package.
