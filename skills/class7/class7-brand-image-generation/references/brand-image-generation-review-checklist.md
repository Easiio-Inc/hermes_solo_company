# Class 7 Brand Image Generation Review Checklist

Use this checklist before approving generated assets for website or presentation use.

## Direction fit

- Does the image clearly match the selected direction?
- Does it support the business positioning rather than generic AI aesthetics?
- Is it consistent with the intended tone and audience?

## Visual consistency

- Are the palette and mood consistent across all generated assets?
- Does the image avoid off-brand colors or random stylistic drift?
- Does it feel compatible with the website or slide design system?

## Composition and usability

- Is there enough negative space for headline, CTA, or slide text?
- Does the crop still work on the target ratio?
- Is the focal subject clear at the intended display size?
- Does the image avoid cluttered micro-details that disappear on slides?

## Text and legibility

- Is text inside the image avoided unless absolutely necessary?
- If text appears, is it non-authoritative and still easy to replace outside the image?
- If OCR will be used later, is the underlying source text available elsewhere?

## Technical checks

- Does the file match the intended dimensions and format?
- Is the filename clear and reusable?
- If Codex was used, was the file saved to the exact expected path?
- If a generator returned multiple candidates, was the winning version clearly identified?

## Handoff

- Is the final prompt saved with the asset?
- Is the target page, section, or slide documented?
- Is fallback alt text or usage guidance included?
