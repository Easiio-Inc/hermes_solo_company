# Class 7 Design System Example

## Brand foundation
- Positioning: fast and credible launch partner for solo founders
- Voice: direct, optimistic, operator-minded

## Color palette
- Primary: Midnight navy
- Accent: Electric teal
- Support: Soft gray, white, muted graphite

## Typography
- Headings: geometric sans
- Body: clean modern sans
- Accent usage: bold only for CTA and metrics

## UI usage
- Homepage hero: bold promise + single strong CTA
- Card styling: soft radius, subtle glow, strong hierarchy
- Social imagery: founder-at-work, dashboards, launch scenes
