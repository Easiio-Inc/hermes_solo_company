# Website Brand Integration Checklist

Use this before saying the Class 7 output is ready for website use.

## homepage hero
- Does the hero headline match the brand promise?
- Is the CTA consistent with the target audience?
- Does the hero image support the positioning?

## Visual consistency
- Are colors reused consistently across cards, buttons, and highlights?
- Does typography match the selected direction?
- Is image treatment coherent across sections?

## Conversion details
- Is the CTA visible above the fold?
- Do service cards and testimonials match the same tone?
- Are social graphics and website sections using the same visual language?
