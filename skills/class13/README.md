# Class 13 Skills

This folder contains reusable skills and supporting classroom materials for **Class 13 — commercialization and launch workflows**.

## Current skills

### `class13-website-skill-recorder-publishing`
Student-editable workflow for turning an approved browser recording into a Hermes-ready website operation skill pack that can later be published for other bots.

## Purpose

Use these assets for repeatable workflows such as:

- capturing a real operator path on a target website
- turning approved browser actions into structured Hermes skill drafts
- reviewing redaction and selector quality before sharing anything with a bot
- packaging a reusable website-operation workflow that can later be published
